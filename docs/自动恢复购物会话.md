# 自动恢复购物会话

2026-10-17，用户明确授权：“以后不要再问我了。你就手动把它切到前台打开，写到文档里面去”。适用于货眼专用 Chrome 的窗口恢复与淘宝首页入口；覆盖旧的暂停窗口恢复约定。

## 默认流程

1. CDP 已连接时调用 `resume_shopping`，不要要求用户恢复最小化窗口或手动打开淘宝首页。
2. 有购物页：优先使用指定 tabId、原绑定页、唯一可见页或唯一购物页，恢复窗口并选择标签，不刷新。多个页面仍无法确定时返回清单，由助手根据任务选择，再传 tabId。
3. 没有淘宝/天猫页面：只复用真正空白的 about:blank；否则先按现有标签预算腾位，再新建固定 `https://www.taobao.com/` 首页。即使以前打开过首页也允许恢复，不删除 navigation-state，不覆盖其他手动页面。
4. 从返回的 state 读取实时搜索控件，按原有语义接口继续。切到其他已有页面时使用 `activate_shopping_tab`，传 `background=true, restoreWindow=true`。
5. CDP 没启动：运行 `scripts/start-chrome-cdp.ps1 -RestoreSession -KeepAlive`，连接后执行上述流程。已有浏览器资料被占用或连接配置不匹配时保留原窗口，不强制重启或删除资料。

```json
{"name":"resume_shopping","arguments":{"out":"output/playwright"}}
```

Python CLI 同样通过 shopping dispatch，operation 为 resume_shopping；不接受目标 URL。`shopping_state` 仍然是只读接口。

## 边界

- 保留10个总标签上限；只按原有规则回收工具创建且可安全关闭的商品页，未知/手动/来源/忙碌页面受保护。
- 不直接打开缓存商品、搜索、店铺地址，不用新首页绕过仍存在的登录或验证码页面。
- 恢复时先显示原窗口，再检查登录/验证；需要用户处理验证时才提出操作请求。网络或未确认的首页导航不自动重试，保留 home-recovery-state.json 的原标签记录。
- 不伪造页面可见性。恢复后核验 Chrome 窗口状态和原生 document.visibilityState；系统最前台和遮挡未经独立验证，仍标记 unverified。
- 不下单、不付款，不改变代理、账户或其他浏览器窗口。
